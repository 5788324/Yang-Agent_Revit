# 语言策略

## 结论

YangAgent Revit 不拆分中文工具箱和英文工具箱，而是采用“一套工具箱 + 设置切换语言”的方案。

## 为什么不同时维护中英两个工具箱

同时维护两个工具箱的问题：

- 功能容易不同步。
- 修复 bug 时要改两份。
- 文档和测试成本翻倍。
- 用户可能装错版本。

## 为什么不只做英文版后期再适配中文

只做英文版的问题：

- 公司内部推广会变慢。
- 普通 Revit 用户理解成本更高。
- 后期改中文容易遗漏弹窗、报告、错误提示。

## 当前方案

采用：

```text
一套代码
一套按钮
一套数据结构
用户可切换语言
```

用户可见文本支持：

- 中文
- English

机器可读数据保持稳定英文：

- JSON key
- CSV 表头
- 内部配置字段
- MCP 工具名

## 实现方式

语言设置保存到：

```text
%APPDATA%\YangAgent_Revit\settings.json
```

设置按钮：

```text
YangAgent -> 系统设置 -> 语言设置
```

所有新按钮必须读取统一语言设置。

## 开发规则

新功能必须满足：

- 有中文界面文案。
- 有 English interface text。
- Markdown 报告跟随语言。
- 弹窗跟随语言。
- pyRevit 输出跟随语言。
- JSON key 保持英文。
- CSV 表头保持英文，方便后续 AI 和脚本解析。
