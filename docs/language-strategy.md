# 语言策略

YangAgent 使用“一套工具、一套代码、设置切换语言”的方案，不拆成中文版工具箱和英文版工具箱。

## 当前规则

- 用户可见文本支持：
  - 中文
  - English
- 机器可读字段保持稳定英文：
  - JSON key
  - CSV header
  - 配置 key
  - 内部主题 id / 工具 id / 状态字段

## 为什么这样做

这样能避免：

- 两套按钮不同步
- 修一次 bug 要改两套
- 文档和测试成倍膨胀
- AI/脚本解析时遇到中英字段漂移

## 当前落点

语言设置由统一设置入口负责。

当前关键要求：

- 所有新按钮必须接语言设置
- 弹窗、报告、提示文字跟随当前语言
- 机器字段不要随 UI 语言变化

## 与主题系统的关系

语言和主题是两套独立设置：

- 语言决定用户可见文字
- 主题决定视觉 token 和样式

不要把主题定义塞回语言文件。
