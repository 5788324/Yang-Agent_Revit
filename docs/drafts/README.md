# Drafts

This folder is for temporary documentation drafts from helper agents.

Rules:

- Drafts can be incomplete.
- Drafts must not include customer data.
- Drafts must not include `.rvt` files or local secrets.
- Hermes should place its first documents here.
- Generated reports may also land here temporarily.
- Drafts are not authority docs.
- Stale drafts should be pruned after their useful content is promoted elsewhere.
