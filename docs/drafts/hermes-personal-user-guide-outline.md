# YangAgent Revit 个人用户指南（大纲草稿）

> 面向个人用户，从安装到日常使用的完整流程。
> 本大纲待 Codex 审查通过后，再填充正文。

---

## 1. 这是什么？

- 一句话定位：个人 Revit 辅助工具箱
- 能做什么：导出、检查、低风险修复
- 不能做什么：不自动改正式模型、不做权限管理
- 和 pyRevit 的关系：pyRevit 是平台，YangAgent 是上面的工具栏

---

## 2. 安装

### 2.1 你需要什么

- Windows（Win10/11 均可）
- Revit 2027（当前只按 2027 处理和验证）
- pyRevit（免费，[下载链接](https://github.com/eirannejad/pyRevit/releases)）
- 本项目文件夹

### 2.2 安装步骤

1. 装 pyRevit → 确认 Revit 中有 pyRevit 选项卡
2. 把本项目放到任意路径
3. 运行 `.\scripts\install-pyrevit-extension.ps1`
4. 重启 Revit → 看到 YangAgent 面板

### 2.3 装不上怎么办

- PowerShell 不能运行脚本 → 用 bypass 模式
- 按钮灰色 → `-Force -ClearCache` 重装
- 找不到 pyRevit 选项卡 → 先装 pyRevit
- 完整排查 → 见 `docs/troubleshooting.md`

## 3. 第一次运行

### 3.1 ⚠️ 先用测试模型

- 找一个单独的 `.rvt` 文件，不要用正式项目
- 为什么：熟悉工具、验证输出、避免误操作

### 3.2 设置语言和导出路径

1. 点击 `系统设置` → 选中文或 English
2. 点击 `导出报告 → 导出路径` → 选一个空文件夹

### 3.3 跑第一个报告

- 点击 `导出模型快照` → 去导出文件夹看 JSON/CSV
- 确认文件生成成功 → 工具链可用

---

## 4. 怎么选导出目录

- 建议每个项目一个独立文件夹
- 不要在 Revit 模型同目录导出
- 不要在 C 盘根目录导出（权限问题）
- 路径尽量简短清楚；如果遇到工具兼容问题，再换成纯英文、无空格路径。

---

## 5. 怎么读报告

### 5.1 你会看到哪些文件

| 文件类型 | 示例 | 用什么打开 |
|---------|------|-----------|
| Markdown (.md) | model_health_report_*.md | 记事本、VS Code、Typora |
| CSV (.csv) | missing_room_numbers_*.csv | Excel |
| JSON (.json) | model_snapshot_*.json | 记事本、VS Code |

### 5.2 各种报告看什么

| 报告 | 重点看 |
|------|--------|
| 模型快照 | 模型基本信息、元素统计 |
| 模型健康报告 | 警告数量、文件大小、问题分类 |
| 回归测试清单 | 工具是否都正常 |
| AI 分析提示词 | 交给 AI 前自动打包好的分析素材 |

### 5.3 预览报告看什么

- 重点关注 "影响数量" → 决定是否值得处理
- CSV 里每行是一个需要处理的问题
- Markdown 里有人类可读的摘要

## 6. 怎么把报告交给 AI 分析

### 6.1 使用 AI 分析提示词

1. 点 `AI分析提示词` → 生成一组文本
2. 把文本和 `model_health_report_*.md` 一起发给 Codex/Claude
3. 附上问题：

```
请分析这份 Revit 模型健康报告，按严重程度列出问题。
只给建议，不要生成会直接修改模型的脚本。
```

### 6.2 注意事项

- 不要让 AI 直接生成修改模型的脚本
- 把 AI 的建议当参考，最终决定你来下
- 不要上传包含客户信息的模型数据

## 7. 怎么安全使用 apply

### 7.1 apply 的正确流程

```
dry-run 预览 → 看 CSV → 人工确认 → apply → 验证 → 需要时 Undo
```

### 7.2 一步一步

1. 点对应预览按钮（如 `预览缺失房间编号`）→ 得到 CSV
2. 用 Excel 打开 CSV，看每行
3. 确认要写什么值、覆盖多少元素
4. 点对应 apply 按钮（如 `应用房间编号`）
5. 在弹出的文件选择框中选择**刚才那个 CSV**
6. 确认弹窗 → 工具写模型

### 7.3 apply 后的检查

- 在 Revit 中肉眼确认几处修改
- 打开 apply 输出的 Markdown 日志检查
- 不满意 → Ctrl+Z 撤销

---

## 8. 怎么撤销

- 每次 apply 在一个 Transaction 中，设计目标是一次 Ctrl+Z 撤销整批；必须在测试模型上验证。
- 如果做了多次 apply → 多次 Ctrl+Z
- Revit Undo 列表里 Transaction 名称清晰（含工具名称）
- ⚠️ 必须在测试模型上验证撤销行为
