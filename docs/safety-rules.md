# Revit AI Agent 安全规则

这份规则约束所有 Codex、Claude Code、Antigravity、MCP、pyRevit 和 C# 插件开发任务。

## 1. 默认只读

Agent 默认只能读取模型、导出数据、生成报告。任何修改模型的操作都必须经过明确确认。

允许的默认操作：

- 读取当前文档信息。
- 读取当前视图信息。
- 导出房间、门窗、视图、图纸列表。
- 生成 JSON、CSV、Markdown、Excel 报告。
- 生成待审查脚本。

## 2. 修改前必须 dry-run

所有修改模型的功能都必须先提供 dry-run。

dry-run 必须输出：

- 将被影响的元素数量。
- 将被影响的 ElementId。
- 将修改的参数名或对象名。
- 修改前后的值。
- 是否存在只读参数、缺失参数、无效元素。

## 3. 高风险操作必须二次确认

高风险操作包括：

- 删除元素。
- 批量修改超过 100 个元素。
- 修改图纸编号。
- 修改房间编号。
- 修改共享参数。
- 保存或同步中心文件。
- 操作链接模型。
- 批量创建或删除视图、图纸、族实例。

## 4. Bridge 和 MCP 限制

禁止在生产环境提供这些接口：

- `execute_code`
- `run_arbitrary_python`
- `run_arbitrary_csharp`
- `delete_elements_without_preview`
- `save_model_without_confirmation`

推荐接口形式：

- `preview_*`
- `apply_*`
- `export_*`
- `get_*`

所有 `apply_*` 工具必须要求用户确认。

## 5. Revit API 事务规则

所有模型修改必须使用 Transaction。失败时必须回滚并输出错误日志。

禁止在没有事务的情况下修改：

- 参数值。
- 元素名称。
- 视图名称。
- 图纸属性。
- 几何对象。
- 族实例。

## 6. 数据边界

不得默认把客户模型数据发送到未经批准的外部服务。

导出数据时应优先使用本地文件：

- JSON。
- CSV。
- Excel。
- Markdown。
- SQLite / DuckDB。

## 7. 测试要求

正式工具发布前必须完成：

- 测试模型验证。
- 空模型或小模型验证。
- 参数缺失场景验证。
- 只读参数场景验证。
- 无选择集场景验证。
- 中文路径和中文参数验证。

## 8. 日志要求

每次执行应记录：

- 任务名称。
- 执行时间。
- Revit 版本。
- 文档标题。
- 是否 dry-run。
- 影响元素数量。
- 成功数量。
- 失败数量。
- 错误信息。
- 输出文件路径。
