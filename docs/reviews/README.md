# Codex Reviews

Use this folder for Codex review records of Hermes, Gemini, DeepSeek, and external toolbox deliveries.

Each review should record:

- source task;
- source package or report;
- changed files;
- checks run;
- safety findings;
- accepted items;
- rejected items;
- required follow-up;
- final decision: `accepted`, `needs changes`, or `rejected`.

No external delivery becomes mainline work until a review record says it is accepted and repository checks pass.
