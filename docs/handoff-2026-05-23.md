## 本机部署方式

每次拉取或开发后，建议执行：

```powershell
cd "D:\codex\Yang Agent_Revit"
.\scripts\install-pyrevit-extension.ps1 -Force -ClearCache
```

然后重启 Revit 或执行 pyRevit Reload。

注意：当前机器提示 `pyRevit command was not found in PATH`，但不影响 extension junction 部署。后续如需命令行 reload pyRevit，可单独配置 pyRevit CLI PATH。

## 开发约束

- pyRevit bundle 目录名必须英文、无空格。
- `bundle.yaml` 不使用 `context:`，避免 pyRevit 2027 availability 加载失败。
- UI 可显示中文，但目录名和数据 key 使用英文。
- JSON/CSV 字段保持英文。
- 只读和 dry-run 工具不能开启 Transaction。
- 修改工具必须：
  - 先有 dry-run CSV。
  - 读取用户选择的 CSV。
  - 显示影响数量。
  - 二次确认。
  - 使用 Revit Transaction。
  - 输出 Markdown 和 CSV 日志。

## 重要修复记录

- pyRevit 2027 中文目录和 `context:` 曾导致按钮灰色，已改为英文目录并移除 `context:`。
- pyRevit 旧缓存曾导致 FullClassName 错误，已新增 `clear-pyrevit-yangagent-cache.ps1`。
- Revit 参数对象不能用 `if not param` 判断，容易误判；应使用 `param is None`。
- 门窗 Mark 读取/写入已支持：
  - `BuiltInParameter.ALL_MODEL_MARK`
  - `LookupParameter("Mark")`
  - `LookupParameter("标记")`
- Revit 2027 / IronPython 创建 `ElementId` 必须显式使用 `ElementId(Int64(value))`，避免重载歧义。
- CSV 读取使用 `utf-8-sig`，避免 BOM 造成字段校验失败。
