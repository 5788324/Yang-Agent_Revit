# Incoming Deliveries

Put external AI or manual deliveries here before Codex review.

Examples:

```text
2026-06-14_gemini_titleblock-tool_v1.zip
2026-06-14_gemini_titleblock-tool_delivery-report.md
2026-06-14_deepseek_level-tool_notes.md
```

Rules:

- Every package must have a delivery report.
- Do not place production `.rvt` or `.rfa` files here.
- Do not place API keys, local credentials, or customer data here.
- Do not treat files in this folder as accepted mainline work.
- Codex must review and explicitly accept work before it is merged.

If a delivery is too large for Git, keep the package outside the repository and put only the report plus local path here.
