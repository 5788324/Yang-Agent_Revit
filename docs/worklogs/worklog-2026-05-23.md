## 上午（继续）- UI 重构与 Bug 修复

### 完成内容（依据用户反馈的 3 个 Bug）

**Bug 1**：Light/Dark 主题切换没有视觉效果
- **根因**：原来 4 个独立的主题按钮只是把主题写入 `settings.json`，没有任何 UI 渲染逻辑。
- **解决**：删除原来的 4 个独立设置按钮，新建 `SystemSettings.pushbutton`（WPF 窗口）。用户选择主题时，窗口背景/前景色会立刻变化，实现真正的所见即所得。

**Bug 2**：运行报告后小弹窗成功提示，但 Revit 主界面跑到后台
- **根因**：`forms.alert()` 是模态弹窗，关掉后焦点无法自动回到 Revit 主窗口。
- **解决**：将所有报告工具中的成功提示 `forms.alert()` 替换为 `forms.toast()`（非阻断式气泡通知），不抢占焦点。

**Bug 3**：系统设置的 4 个功能太分散；报告功能没有折叠下拉菜单
- **解决**：
  - `Settings.panel`：原来的 4 个按钮（语言、主题、用户、关于）合并为 1 个 `SystemSettings` 按钮。
  - `Reports.panel`：新建 `Reports.pulldown` 下拉菜单，将 4 个报告工具统一收纳其中。

### 关键技术陷阱（同事记录，后续所有人必知）
| 场景 | 错误做法 | 正确做法 |
|:--|:--|:--|
| Revit 2027 创建 ElementId | `ElementId(int_value)` | `ElementId(Int64(int_value))` |
| 判断 Revit 参数是否存在 | `if not param:` | `if param is None:` |
| CSV 读取 UTF-8 | `open(f, 'r')` | `codecs.open(f, 'r', 'utf-8-sig')` |
| 门窗 Mark 读取 | 只用内置参数 | 同时兼容中英文 LookupParameter |
| bundle 目录命名 | 含中文/空格 | 纯英文无空格 |
| bundle.yaml 可用性 | 使用 `context:` | 删除 context，不做可用性声明 |
