# External Rewrite Contract

Use this contract for any Gemini or other external tool before implementation starts.

## Contract

The external tool must be treated as:

- idea source
- workflow reference
- UI/command inventory source

The external tool must not be treated as:

- mainline architecture
- direct patch source
- accepted UI standard
- accepted safety model

## Rewrite Requirements

Every rewritten tool must:

- be assigned a YangAgent target feature name
- adopt YangAgent naming and grouping
- use shared theme tokens
- avoid hardcoded window color systems
- follow YangAgent safety flow for model changes
- record live validation expectation before acceptance

## Forbidden Carryovers

Do not preserve by default:

- dynamic code execution
- auto-start MCP write behavior
- broad batch mutation workflows without preview/confirmation
- ad-hoc WPF styling copied directly from the source toolbox
- source terminology that conflicts with YangAgent vocabulary
