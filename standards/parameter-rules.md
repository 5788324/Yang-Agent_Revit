# Parameter Rules

本文件记录当前可继续扩充的参数标准占位规则。

## 当前状态

这是参数标准的轻量占位稿，不是完整定版规范。

## 当前最有用的参数范围

| 参数 | 主要用途 | 是否高优先级 |
| --- | --- | --- |
| `Mark` / 标记 | 门窗等编号检查 | 高 |
| 房间编号 | 房间编号检查与补全 | 高 |
| 用途 | 房间分析与校验 | 中 |
| 备注 | 通用说明 | 中 |

## 当前规则

- 必填参数不应为空
- 编号类参数应避免重复
- 只读参数不作为批量写入目标
- preview/apply 工具只应操作明确受控的参数范围

## 与主线功能的关系

如果某个参数将进入批量检查或批量写入：

1. 先确认参数语义稳定
2. 再确认它是否适合进入 preview/apply
3. 再补充对应的错误码、日志和 Undo 说明
